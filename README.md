# 📊 PRO.1 – Excel Fundamental Booster

A beginner-friendly **Microsoft Excel practice project** designed to develop strong spreadsheet skills through formulas, functions, data management, and practical data analysis.

This project focuses on learning essential Excel concepts and applying them to real-world business and data-related scenarios.

---

## 📌 Project Overview

**PRO.1 – Excel Fundamental Booster** is a practical Excel learning project created to strengthen the fundamentals of Microsoft Excel.

The project contains an Excel workbook named `PR_1.EXCEL.xlsx`, which focuses on important spreadsheet operations, logical calculations, conditional functions, lookup techniques, text manipulation, date and time calculations, and data filtering.

The main goal is to understand how Excel functions work, how formulas can simplify calculations, and how spreadsheet tools can be used to organize and analyse business data.

This project is suitable for beginners who want to build a strong foundation in Excel before moving towards advanced data analysis tools such as SQL, Python, and Power BI.

## ⚠️ Excel Version Compatibility

Some advanced functions require newer versions of Microsoft Excel.

For example:

- **Excel 2013:** Supports functions such as VLOOKUP, HLOOKUP, INDEX, MATCH, IF, COUNTIFS, SUMIFS, and many traditional text and date functions.
- **Microsoft 365 / Newer Excel:** Supports newer functions such as XLOOKUP, XMATCH, FILTER, and TEXTSPLIT.

If a function displays `#NAME?`, check whether your Excel version supports that function.
